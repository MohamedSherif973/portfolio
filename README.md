# Mohamed Sherif — Portfolio

A React portfolio built with Vite.

## Run locally

```bash
npm ci
npm run dev
```

## Check and build

```bash
npm run lint
npm run build
```

The production build is generated in `dist/`.

## GitHub Pages build

Vite is configured with `/portfolio/` as its base path for this repository.
The repository contains the project source; publishing a live site requires a
separate GitHub Pages deployment workflow and repository Pages configuration.
