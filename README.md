# Mohamed Sherif — Portfolio

A React portfolio built with Vite.

## Run locally

```bash
npm ci
npm run dev
```

## Check and build

```bash
npm run lint
npm run build
```

The production build is generated in `dist/`.

## GitHub Pages

This project is configured for the repository site at
`https://mohamedsherif973.github.io/portfolio/`. In the repository settings,
open **Pages** and select **GitHub Actions** as the build and deployment source.
